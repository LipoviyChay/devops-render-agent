# DevOps Render Agent

Demonstration web application deployed by an AI agent for DevOps homework.
The deployment agent is ChatGPT/Codex; this application serves the requested HTML page.

Run: npm start
Build command on Render: npm install
Start command on Render: npm start
Instance type: Free
The server listens on 0.0.0.0 and uses the PORT environment variable.
No API keys or external dependencies are required.
